# Хоткеи в любой раскладке

**Применимость:** любое приложение на gpui.

- gpui на Windows берёт клавишу сочетания через `MapVirtualKeyW(vk, MAPVK_VK_TO_CHAR)` — для букв это
  латиница в любой раскладке; символ раскладки отдельно в `key_char`. Привязки `ctrl-e`, `j` работают
  в русской раскладке без патчей.
- Клавиши без модификаторов (буквы, стрелки, Home/End, PgUp/PgDn) привязывать с условием `!Input`
  (`"Screen && !Input"`): иначе в поле ввода они срабатывают как команды и не печатаются.
- Проверка — скрипт: запустить с журналом нажатий, переключить окно в нужную раскладку сочетанием смены
  языка (из `HKCU\Keyboard Layout\Toggle`), убедиться по `GetKeyboardLayout`, что раскладка сменилась,
  и нажимать клавиши только пока окно приложения на переднем плане.

**Откуда.** Postman S1-01 (`scripts/keys-ru.ps1`); в Урфине — S0-contracts-v4 №5.
