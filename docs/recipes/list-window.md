# Список: окно строк в фоне

**Применимость:** длинные виртуальные списки (письма, файлы).

**Проблема.** Чтение строк из хранилища в потоке интерфейса даёт рывки; `uniform_list` gpui ещё и
меряет высоту строки, вызывая обработчик с диапазоном `0..1`, — если принять его за видимую область,
каждый кадр перечитывается окно вокруг строки 0.

**Решение.**
- Одну строку (`range.len() == 1`) не считать видимой областью.
- Окно строк (видимое ± запас) читать фоновой задачей; следующее запрашивать заранее, когда до края
  загруженного меньше половины запаса; ответы на устаревшие запросы отбрасывать по номеру запроса.
- Пока строк нет — пустая строка той же высоты; выбранный элемент открыть, когда придёт его страница.
- Первое окно папки — сразу, чтобы первый кадр был со строками.
- Запись (пометки) — в отдельном потоке с очередью: коммит хранилища — это fsync.

**Результат.** Худший кадр прокрутки 10–36 → 9 мс; запись флагов 30 мс → вне кадра.

**Откуда.** Postman S1-02 (поток записи флагов), S1-03 (окно строк).
