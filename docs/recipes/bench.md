# Бенч и сравнение

**Применимость:** любое приложение.

- Один сценарий для сравниваемых вариантов, итог — строка `key=value`: интервалы кадров (p50/p99/max)
  по фазам, CPU процесса и потока интерфейса, рабочий набор и private bytes (пик и простой), размер exe,
  простой после сценария.
- Фазы — реалистичные (прокрутка без открытия элементов) и худший случай (открытие на каждом кадре).
- Свежие данные на каждый прогон (копия шаблона), иначе прогоны отличаются (пометки «прочитано» копятся).
- Ноутбук шумит: сравнивать **чередованием** бинарей (A, B, C, A, B, C…), медианы по 3–4 прогонам.
- Перед сравнением — частота экрана и питание: от батареи экран может уйти на 60 Гц, все интервалы и CPU
  меняются.
- Переменные окружения для удлинения фаз — под профилировщик.

**Откуда.** Postman `crates/core/src/bench.rs`.
