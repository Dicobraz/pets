# Экран из кэшируемых view

**Применимость:** любое приложение на gpui.

**Проблема.** Если экран — одно view, gpui на каждом кадре заново раскладывает и рисует всё окно
(taffy ~50 % времени кадра). Прокрутка списка перестраивает и панель чтения, и папки.

**Решение.** Экран — набор view со своим состоянием (список, папки, панель чтения, строка команд);
родитель встраивает их через `entity.cached(StyleRefinement::default()…)` с явным размером — кэшированное
view не измеряется по содержимому. Изменение — `cx.notify()` своего view (грязное view делает грязными
и родителей); связь частей — событиями (`EventEmitter`), не чтением чужого состояния в `render`
(кэш не узнает об изменении).

**Результат.** Поток интерфейса при прокрутке списка 65,5 → 48 % (egui 44,5 %), худший кадр 14,2 → 8,8 мс.

**Откуда.** Postman S1-06 (`app-gpui/src/main.rs`).
