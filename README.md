# Pets

Общий код и рецепты приложений семейства «Pets» (Postman, Урфин и следующие). Интерфейс всех
приложений — на gpui; egui сюда не попадает.

## Крейты

| Крейт | Подход | Что внутри | Статус |
|---|---|---|---|
| `pets-commands` | действия пользователя | реестр команд: id, ключ названия, хоткеи по умолчанию, контекст; без UI | есть |
| `pets-gpui-windows` | платформа gpui | патч Windows-платформы gpui: кадры по запросу, живой ресайз, шейдеры в exe | план (из Postman) |
| `pets-i18n` | тексты | Fluent, локаль ОС, проверка на сырые строки; тексты `.ftl` — в приложении | план |
| `pets-shell` | жизнь процесса | единственный экземпляр, tracing + журнал Windows, пути профиля и portable | план |
| `pets-ui` | визуальный язык на gpui | токены Fluent, тосты, подтверждение одной строкой, команды → действия gpui | план |

Крейт появляется, только когда его использует хотя бы одно приложение. Предметное (почта, файлы)
остаётся в приложениях.

## Рецепты

`docs/recipes/` — проверенные подходы, по одному на файл, с пометкой, где применимы. Это знания,
а не код: брать в приложение, если подходит его специфике.

## Подключение

```toml
pets-commands = { git = "https://github.com/Dicobraz/pets", rev = "<коммит>" }
```

Совместная правка приложения и `pets` — локальный `[patch."https://github.com/Dicobraz/pets"]` на путь,
в коммит не попадает.
